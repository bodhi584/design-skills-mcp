Add the design skills MCP to your agent

Pick your app, paste, refresh. Then ask something like “Find a design skill for my landing page”.

~/.gemini/config/mcp_config.json. Remote servers need serverUrl, not url: with url Antigravity loads no tools and shows no error.

{
  "mcpServers": {

The 8 MCP tools your agent gets

All read-only. The first four help the agent design the page itself; the last four point it to installable skills, with our verdict, test result and safety flags.

design_direction
From a one-line brief (and your brand color, if you have one): light and dark color tokens with every text pair checked to WCAG AA, CSS variables, a font pairing, type scale, radius, the layout and hero to build, and what to avoid for that kind of product.
lint_design
Checks HTML and CSS, or a live URL: labels, alt text, heading order, focus, zoom, contrast (theme tokens too), and generated-page tells such as eyebrow labels, gradient washes and template copy. Each finding comes with a fix.
check_contrast
Exact WCAG ratios for up to 50 color pairs, and the nearest passing color when one fails.
design_checklist
Before-build and pre-launch checklists.
find_design_skills
The best skills for a task in plain words. Filters: offline, no API key, tested only, instructions only.
get_design_pipeline
An ordered skill combination for a goal, and why each step is there. This is what the box above calls.
get_skill
The full review of one skill, plus a ready-to-paste install prompt for Antigravity.
list_design_skills
Every skill and pipeline in the library.

Who it is for

Good for

People who build pages and apps with an agent and do not want to compare design skills by hand, and teams that want one shared, checked list.

Not for

Installing skills silently: it never writes to your machine. Non-design skills: SEO, data and DevOps reviews are on our reviewed list. Install prompts are written for Antigravity, and 4 skills are static reviews only.

FAQ

What is the Design Skills MCP?

A free, hosted MCP server from antigravityskills.org with 8 design tools. Your coding agent can get a design direction with contrast-checked tokens, lint its HTML for accessibility and generic AI-design tells, search 25 design skills we reviewed (21 of them run by us in Antigravity 2.0), get an ordered skill combination for a goal, and get an install prompt for the one it picks.

Is it free? Do I need an API key?

It is free, and you need no key or login. It is a public, read-only server; we only count which tools are called.

Does it install skills for me?

No. It returns our verdict, safety flags and a link to the install guide. Your agent installs the skill from its source repository and asks you first. We do not copy or redistribute skill files.

Which clients work?

Any client that supports remote MCP over Streamable HTTP. We connected it with the official MCP TypeScript SDK on 2026-11-26; setup for Antigravity, Claude Code, Cursor, VS Code and Windsurf is above.

Why does Antigravity show no tools?

Antigravity needs the key serverUrl for remote servers. With url it loads nothing and shows no error. Rename the key and refresh Installed MCP Servers.

How is this different from a skills directory MCP?

Directory servers list everything they can find. This one only holds design skills we reviewed, says which ones we actually ran and what broke, and gives ordered pipelines, for example design tokens, then components, then an accessibility audit.

How often is the data updated?

When we review or re-test a skill. Every answer includes data_updated; the current data is from 2026-11-26.

Can I use it with Claude Code or Cursor?

Yes for search, verdicts and pipelines. The ready-made install prompts target Google Antigravity (.agents/skills/); for Claude Code, use the source repo link in each result.
